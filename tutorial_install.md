# 📱 Panduan Instalasi Aplikasi SIMAGANG

Aplikasi SIMAGANG Humas Pendis menggunakan teknologi **PWA (Progressive Web App)**. Artinya, aplikasi ini tidak perlu diunduh dari App Store atau Play Store yang memakan memori besar, melainkan bisa langsung di-install dari browser!

Berikut adalah cara mengakses dan mengunduhnya di berbagai perangkat:

---

## 🟢 Untuk Pengguna Android (Google Chrome)

1. Buka aplikasi **Google Chrome** di HP Android Anda.
2. Kunjungi link aplikasi SIMAGANG: `https://creativeflow-am.github.io/simagang-humaspendis/` *(atau link Vercel jika Anda memindahkannya)*.
3. Setelah halaman terbuka, ketuk **ikon titik tiga (⋮)** di pojok kanan atas browser Chrome Anda.
4. Pilih menu **"Tambahkan ke Layar Utama"** *(Add to Home Screen)* atau **"Instal Aplikasi"** *(Install App)*.
5. Akan muncul kotak konfirmasi, klik **"Tambahkan"** / **"Instal"**.
6. **Selesai!** Cek layar utama (Home Screen) HP Anda, aplikasi SIMAGANG kini sudah terpasang layaknya aplikasi biasa lengkap dengan logo Kemenag.

---

## 🍎 Untuk Pengguna iPhone / iOS (Safari)

*Catatan: Instalasi PWA di iOS wajib menggunakan browser bawaan Apple, yaitu **Safari**.*

1. Buka aplikasi **Safari** di iPhone/iPad Anda.
2. Kunjungi link aplikasi SIMAGANG: `https://creativeflow-am.github.io/simagang-humaspendis/`.
3. Setelah halaman terbuka, ketuk ikon **Bagikan (Share)** di bagian bawah tengah layar (ikon berbentuk kotak dengan panah ke atas 📤).
4. Geser layar agak ke bawah, lalu pilih opsi **"Tambah ke Layar Utama"** *(Add to Home Screen)* yang berlogo kotak dengan tanda plus (➕).
5. Di kanan atas layar, ketuk tombol **"Tambah"** *(Add)*.
6. **Selesai!** Aplikasi SIMAGANG sekarang sudah terpasang di layar utama iPhone Anda.

---

## 💻 Untuk Pengguna Laptop/PC (Chrome / Edge)

1. Buka **Google Chrome** atau **Microsoft Edge** di laptop/komputer.
2. Kunjungi link aplikasi SIMAGANG.
3. Di ujung kanan *address bar* (tempat Anda mengetik URL), Anda akan melihat **ikon monitor kecil dengan tanda plus** atau tulisan **"Install SIMAGANG"**.
4. Klik ikon tersebut, lalu pilih **"Install"**.
5. **Selesai!** Aplikasi akan langsung terbuka di jendela *desktop* tersendiri yang lebih profesional dan *shortcut*-nya akan muncul di Desktop/Start Menu Anda.
